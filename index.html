      Incident flow and who does what

      1. DetectionMonitoring alert (failed run, freshness or quality check) or a data consumer report. Ticket created immediately.
      2. TriageSeverity set with the tech lead; business impact confirmed with the affected consumers.
      3. CommunicationFirst message to consumers within the response target, then at the agreed frequency.
      4. ResolutionFix, backfill or workaround by the engineering team. The project manager tracks the deadline and prepares the closure message.
      5. Post-incident reviewFor P1 and P2: causes, preventive actions, owners and due dates, logged in the RAID log.

      How each metric is computed

      • Freshness SLA hit rate: runs that finished before the agreed deadline, divided by all scheduled runs. A failed run counts as a miss.
      • Run success rate: runs that did not fail, divided by all runs. A late but successful run counts as a success.
      • Data quality test pass rate: automated tests passed, divided by tests run, over completed runs.
      • Median recovery time: from a failed run to the next successful run. The median is used because a few long outages would distort a mean.
      • Median run duration: start to finish. Useful as a signal of cost and headroom before the deadline.

      Data sources in practice: run history from the orchestrator, test results from the transformation and quality tooling, deadlines from the agreed SLA. The tech lead owns this tooling.

      Guardrails

      • Never paste personal data or production records. Use aggregates, counts and placeholders. Replace source, people and product names if the tool is not approved for confidential data.
      • AI drafts, people decide. Read every output before it goes to a data owner or a steering committee.
      • Check numbers and dates against the trackers. AI can misread or invent them.
      • Technical choices stay with the tech lead. Use AI to prepare questions, not verdicts.
      • Be transparent. Follow your organisation's policy on disclosing AI-assisted documents.
